# Sway public copy truth matrix

**Status:** Required copy and indexability guardrail. Public text must describe verified behavior, not roadmap intent.

## Audience language

The durable umbrella is **independent talent, creators, and gig professionals**. Comedians are the first focused acquisition wedge, not the only audience. Context-specific terms may include comedians, singers, songwriters, DJs, musicians, hosts, bartenders, event professionals, vendors, and service professionals. Existing performer and talent terminology may remain where it describes current Live Rooms or compatibility routes.

## Organic qualified pro signup

The primary acquisition metric is **OQPS: organic qualified pro signup**. An OQPS is a signup attributable to an unpaid organic source where the person is verified, active, unrestricted, owns a valid profile, and completes that profile within 14 days. First value is measured separately and means a real qualified action within 30 days, such as an eligible publication, a genuine inquiry, an active-room outcome, or another capability-specific event that is not a demo or synthetic record.

Raw account creation, preview records, duplicate accounts, test fixtures, bots, staff accounts, and unverifiable attribution do not count as OQPS. Measurement must deduplicate durable conversion events and keep acquisition intent separate from settings edits or unrelated telemetry.

## Copy review rule

Before public copy changes, map every promise to its route, persisted authority, observed behavior, and evidence. If any one is absent, narrow the wording or keep it private. A successful build, a test fixture, a configured provider, or a deployed page is not proof that a customer outcome occurred.
